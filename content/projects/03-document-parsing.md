# 문서 파싱 시스템

## 한 줄 요약
다양한 포맷의 문서를 구조 그대로 파싱하고, 개인정보를 찾아 비식별화한 뒤 원본 서식으로 다시 조립하는 시스템.

## 배경 / 문제
문서 안의 개인정보를 가려야 하는데, 문서는 포맷마다(OOXML, PDF, 한컴, ODT) 내부 구조가 전혀 다르다.
또 텍스트만 가려서는 부족하다 — 표, 도형, 텍스트박스, 차트, 이미지 안의 글자까지 모두 처리해야 하고,
가린 뒤에도 원본 레이아웃이 깨지지 않아야 한다.
같은 문서처럼 보여도 포맷마다 텍스트와 서식 데이터가 저장되는 위치와 표현 방식이 달라, 하나의 공통 처리 방식만으로는 대응하기 어려웠다.

## 내가 한 일
- **다중 포맷 파싱**: OOXML(docx/pptx/xlsx), PDF, 한컴 문서, ODT 파싱
- **포맷별 구조 분석**: 각 문서 포맷의 데이터 저장 구조와 서식 표현 방식을 분석해 포맷별 처리 로직 구현
- **비식별화**: Regex 기반 패턴 탐지 + 이미지 내 텍스트는 OCR로 추출해 마스킹
- **문서 재구성**: 비식별화 결과를 반영한 뒤 원본 서식과 레이아웃이 깨지지 않도록 재조립
- **요소별 커버리지**: 본문 텍스트, 표, 차트, 도형, 텍스트박스, 이미지 OCR 텍스트

## 사용 기술
Java · Spring Boot · OCR · Regex

## 성과
서로 다른 내부 구조를 가진 여러 문서 포맷을 파싱하고, 개인정보 비식별화 후에도 기존 서식과 레이아웃을 최대한 유지하도록 문서를 재구성하는 파이프라인을 개발했다.

## 배운 점 / 어려웠던 점
가장 어려웠던 부분은 문서 포맷마다 데이터와 서식을 저장하는 구조가 다르다는 점이었다.
각 포맷의 구조를 개별적으로 이해하고 처리하면서도, 비식별화 과정에서 원본 문서의 서식이 깨지지 않도록 보존하는 데 중점을 두었다.
