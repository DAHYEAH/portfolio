# 보행 로봇 안정성 제어 알고리즘

## 한 줄 요약
시뮬레이션 환경에서 강화학습으로 보행 로봇이 넘어지지 않고 걷도록 하는 제어 알고리즘을 개발.

## 배경 / 문제
실제 로봇으로 보행 학습을 시키면 넘어질 때마다 하드웨어가 손상되고 시도 횟수도 제한된다.
시뮬레이션에서 학습해 안정적인 제어 정책을 먼저 확보할 필요가 있었다.

## 내가 한 일
- 시뮬레이션 기반 강화학습 보행 안정성 제어 알고리즘 개발
- YOLO 기반 객체 탐지 적용 (주변 인식)

## 사용 기술
Python · YOLO · 강화학습 · 시뮬레이터

## 성과
> 📝 채워넣기: 사용한 시뮬레이터(MuJoCo/Gazebo/Isaac 등), RL 알고리즘(PPO/SAC 등), 보행 성공률·유지 시간

## 배운 점 / 어려웠던 점
