# 돈사 현황판 수기 숫자 OCR 앱 (캡스톤)

## 한 줄 요약
돈사 현황판에 손으로 쓴 숫자를 카메라로 찍어 자동 전산화하는 앱. 서버·백엔드·앱까지 풀스택으로 구현.

## 배경 / 문제
농장에서는 현황판에 손으로 숫자를 적고, 이를 사람이 다시 컴퓨터에 옮겨 적는다.
수기 숫자는 칸을 넘나들며 겹쳐 쓰이는 경우가 많아, 검출 영역이 서로 중복되면 인식이 틀어진다.

## 내가 한 일
- **수기 숫자 검출영역 중복 분리 알고리즘 개발** (핵심 기여)
- 서버 구축 (AWS)
- 백엔드 개발 (Flask)
- Flutter 모바일 앱 개발

## 사용 기술
Python · PyTorch · Flask · Flutter · AWS
