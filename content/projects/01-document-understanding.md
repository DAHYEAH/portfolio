# 문서 이해 모델 개발

## 한 줄 요약
문서 이미지에서 텍스트와 표 구조를 읽어내는 OCR·TSR 모델을 학습하고, 실제 서비스에 태울 수 있도록 추론까지 최적화한 프로젝트.

## 배경 / 문제
다양한 문서와 이미지에서 글자를 OCR로 추출하고, 그 안의 개인정보를 찾아 비식별화하는 것이 목적이었다.
범용 OCR 모델은 실제 고객 문서의 서식·스캔 품질과 다양한 수기체에서 정확도가 떨어질 수 있고,
연구용 모델을 그대로 서비스에 올리면 추론 속도가 요구 수준을 못 맞춘다.
특히 수기체 인식 성능을 높이면서도 사용자별 학습이 빠르게 끝나고, 새 데이터를 학습한 뒤 기존 인식 능력이 망각되지 않도록 하는 것이 중요한 과제였다.

## 내가 한 일
- **데이터셋 구축 및 품질 개선**: 수기체를 포함한 OCR 학습 데이터를 구축하고 정제·검수해 라벨 품질 향상
- **OCR 모델 학습·실험**: 여러 OCR 모델을 비교하고 증류학습을 적용했으며, 모델 구조 일부를 변경하며 성능 검증
- **사용자별 어댑터 학습**: 사용자별 모델 학습 기능을 제공하고, 학습 시간을 줄이면서 기존 지식의 망각을 방지하는 방향으로 개선
- **추론 최적화**: TensorRT와 Triton Inference Server를 적용해 서비스 추론 시간 단축
- **문자 좌표 계산**: 인식된 문자 단위의 좌표값을 계산해 개인정보 비식별화에 활용
- **개인정보 비식별화 연계**: 문서·이미지에서 인식한 개인정보를 찾아 마스킹하는 파이프라인에 OCR 적용
- **표 구조 인식 (TSR)**: 표의 행/열/셀 구조를 복원하는 모델 적용

## 사용 기술
Python · PyTorch · TensorRT · Triton Inference Server

## 성과
데이터셋 구축부터 모델 실험, 문자 좌표 후처리, 사용자별 학습, TensorRT·Triton 기반 서빙 최적화까지 OCR의 학습과 서비스 적용 전 과정을 수행했다.
다양한 문서와 이미지의 개인정보 비식별화에 활용할 수 있도록 수기체 인식과 추론 효율을 함께 개선했다.

## 배운 점 / 어려웠던 점
수기체처럼 편차가 큰 데이터를 안정적으로 인식하는 문제와 사용자별 추가 학습의 효율을 동시에 확보하는 것이 어려웠다.
특히 짧은 시간 안에 새 필체를 학습하면서 기존에 학습한 문자 인식 능력을 잃지 않도록 하는 망각 방지 문제를 중점적으로 다뤘다.
단일 모델 구조에 의존하지 않고 데이터 품질 개선, 다양한 모델 비교, 증류학습, 구조 변경, 어댑터 학습을 함께 실험했다.
